# Спецификация базовой модели

## Назначение документа

Этот документ фиксирует правила первой, генетической версии модели. Его цель - сделать условия экспериментов однозначными, воспроизводимыми и отделить обязательную модель от последующих расширений.

## Исследовательский вопрос

При каких условиях локальные повторяющиеся взаимодействия и ограниченные ресурсы способствуют возникновению и сохранению условного сотрудничества?

## Границы базовой версии

В базовой версии наследуется только генетическая стратегия повторяющейся дилеммы заключённого. Культурное обучение, целенаправленный поиск ресурсов, ошибки действий и память длиннее одного раунда в неё не входят.

## Пространство и ресурсы

- Мир - квадратная решётка размера `L × L` с тороидальными границами.
- Окрестность агента - восемь соседних клеток (окрестность Мура).
- В клетке может находиться не более одного агента.
- В клетке может находиться не более одного ресурса.
- Ресурс появляется в клетке без ресурса с вероятностью `q` на каждом такте.
- Агент, оказавшийся на клетке с ресурсом, забирает его и получает энергию `R`; ресурс исчезает.

Тороидальные границы исключают особые условия у края карты. Ограничение одной особью на клетку делает соседство и локальные встречи однозначными.

## Состояние агента

Каждый агент имеет:

- координаты на решётке;
- текущую энергию `E`;
- генотип из пяти бинарных генов;
- состояние «жив» или «мёртв».

Генотип имеет вид `g = (g0, gCC, gCD, gDC, gDD)`, где каждый ген равен `C` или `D`:

| Ген   | Значение                                         |
| ----- | ------------------------------------------------ |
| `g0`  | Первый ход во встрече                            |
| `gCC` | Ход после собственного `C` и ответа партнёра `C` |
| `gCD` | Ход после собственного `C` и ответа партнёра `D` |
| `gDC` | Ход после собственного `D` и ответа партнёра `C` |
| `gDD` | Ход после собственного `D` и ответа партнёра `D` |

Всего существует 32 генотипа. Например, стратегия «око за око» записывается как `C C D C D`.

## Поколение и порядок такта

Поколения не перекрываются: потомки не появляются, пока живут агенты текущего поколения. Одно поколение длится фиксированное число `T` тактов либо завершается раньше при вымирании всей популяции.

На каждом такте выполняются следующие действия:

1. На клетках создаются новые ресурсы по правилу восстановления.
2. Каждый живой агент случайно выбирает одну свободную клетку из своей окрестности или остаётся на месте.
3. Агент забирает ресурс с клетки, на которой находится.
4. Живые соседи случайно объединяются в пары; агент может участвовать не более чем в одной встрече за такт.
5. Каждая сформированная пара играет повторяющуюся дилемму заключённого из `K` раундов.
6. Рассчитывается изменение энергии; агент с `E ≤ 0` погибает и больше не участвует в этом поколении.

Случайное движение является намеренно нейтральным: оно не добавляет отдельную стратегию поиска ресурсов и позволяет исследовать прежде всего эволюцию социальных стратегий.

## Повторяющаяся дилемма заключённого

Встреча длится `K = 5` раундов. В первом раунде агент использует `g0`. В каждом следующем раунде он выбирает действие по исходу предыдущего раунда со своей точки зрения.

Используется следующая матрица выигрышей:

| Действия пары | Выигрыш первого | Выигрыш второго |
| ------------- | --------------: | --------------: |
| `C, C`        |               3 |               3 |
| `C, D`        |               0 |               5 |
| `D, C`        |               5 |               0 |
| `D, D`        |               1 |               1 |

Пять раундов — стартовое значение, а не универсальная константа. Оно позволяет проявиться условным реакциям несколько раз и сохраняет сопоставимый вклад ресурсов и игры. В экспериментальном контроле будет использовано `K = 1`.

## Энергия, смерть и приспособленность

После такта энергия агента изменяется по формуле:

`E(t + 1) = E(t) + R_i + α × Π_i − c`,

где `R_i` — энергия от ресурса, `Π_i` — сумма выигрышей в игре за такт, `α` — вес игрового выигрыша, а `c` — стоимость существования.

Агент погибает при `E ≤ 0`. Его приспособленность равна нулю. Для агента, дожившего до конца поколения, приспособленность равна его конечной энергии:

`F_i = E_i(final)`.

Такое правило делает ресурсы источником базового выживания, а игру — дополнительным фактором отбора. Если выживает ноль агентов, запуск фиксируется как вымирание популяции и не продолжается искусственным восстановлением.

## Формирование следующего поколения

В конце поколения из живых агентов создаётся новое поколение фиксированной численности `N`:

1. Для каждого родителя проводится турнир среди трёх случайных выживших; выбирается агент с наибольшей приспособленностью.
2. Два выбранных родителя с вероятностью `pc` проходят одноточечное скрещивание пятигенной стратегии; иначе потомок копирует одного из родителей.
3. Каждый ген потомка меняется `C ↔ D` независимо с вероятностью `pm`.
4. Потомок получает энергию `E0` и случайную свободную клетку.

После создания потомков агенты прежнего поколения удаляются, а ресурсный слой создаётся заново по одним и тем же параметрам.

## Предлагаемые стартовые параметры

| Параметр                           | Обозначение | Предлагаемое значение | Диапазон эксперимента |
| ---------------------------------- | ----------- | --------------------: | --------------------: |
| Размер стороны мира                | `L`         |                    30 |                 20–60 |
| Численность популяции              | `N`         |                   450 |   плотность 0,25–0,75 |
| Тактов в поколении                 | `T`         |                    50 |                20–100 |
| Раундов во встрече                 | `K`         |                     5 |           1, 3, 5, 10 |
| Начальная энергия                  | `E0`        |                    10 |                  5–20 |
| Энергия ресурса                    | `R`         |                     4 |                   2–8 |
| Стоимость такта                    | `c`         |                     1 |                 0,5–2 |
| Вероятность восстановления ресурса | `q`         |                  0,10 |             0,02–0,25 |
| Вес игры в энергии                 | `α`         |                  0,20 |                0–0,50 |
| Вероятность скрещивания            | `pc`        |                  0,80 |                   0–1 |
| Мутация одного гена                | `pm`        |                  0,01 |                0–0,05 |
| Размер турнира                     | —           |                     3 |                   2–5 |

Предлагаемые значения не являются результатами исследования. Они служат исходной точкой и должны быть закреплены перед началом серии экспериментов.

## Расширения после базовой модели

После проверки базовой версии могут быть добавлены:

- культурная передача поведенческой таблицы между соседями;
- наследуемые параметры поиска ресурсов и движения;
- ошибки выполнения действий;
- память о нескольких предыдущих раундах;
- неоднородная среда и разные режимы дефицита ресурсов.
