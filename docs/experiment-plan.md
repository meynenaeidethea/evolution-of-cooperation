# План вычислительных экспериментов

## Цель

Проверить, как повторяемость и локальность взаимодействий, параметры генетического алгоритма и ресурсная среда влияют на сотрудничество, состав стратегий и выживаемость популяции.

## Общие правила воспроизводимости

- Для каждого сценария выполняется не менее 30 независимых запусков.
- Для каждого запуска сохраняются номер сценария, все параметры, начальное значение генератора случайных чисел и результаты по поколениям.
- Один запуск не используется как доказательство гипотезы; выводы делаются по распределению результатов повторов.
- При сравнении сценариев изменяется один фактор, если цель эксперимента не требует исследовать их взаимодействие.

## Базовый сценарий

Базовым считается режим из [спецификации модели](model-specification.md): локальные взаимодействия, `K = 5`, случайное движение, предлагаемые стартовые параметры среды и генетического алгоритма.

Этот сценарий нужен как точка отсчёта для всех сравнений, а не как заранее ожидаемый «правильный» результат.

## Серии экспериментов

### 1. Повторяемость игры

Сравнить `K = 1`, `K = 3`, `K = 5` и `K = 10` при неизменных остальных параметрах.

Проверяемое утверждение: повторяющиеся встречи чаще поддерживают условное сотрудничество, чем однократная игра.

### 2. Вес игры в энергетическом балансе

Сравнить `α = 0`, `0,1`, `0,2`, `0,35` и `0,5`.

Проверяемое утверждение: игра влияет на генетический состав только тогда, когда её вклад в энергию заметен; устойчивость сотрудничества может меняться нелинейно.

### 3. Локальность взаимодействий

Сравнить базовый локальный режим с контрольным режимом, в котором партнёр для игры выбирается случайно из всей живой популяции.

Проверяемое утверждение: локальность увеличивает пространственную кластеризацию и может изменять устойчивость условного сотрудничества.

### 4. Мутация

Сравнить `pm = 0`, `0,005`, `0,01`, `0,02` и `0,05`.

Проверяемое утверждение: высокая мутация поддерживает разнообразие, но способна препятствовать закреплению успешной стратегии.

### 5. Ресурсная среда

Изменять вероятность восстановления `q` и энергию ресурса `R` в пределах, заданных спецификацией.

Проверяемое утверждение: ресурсный режим влияет на выживаемость и на относительную роль выигрышей игры в приспособленности.

## Метрики

Для каждого поколения и запуска сохраняются:

- доля действий `C` в первом раунде и во всех раундах;
- частоты всех 32 генотипов и доли наиболее частых стратегий;
- средняя и максимальная конечная энергия;
- доля выживших и факт вымирания;
- средняя энергия, полученная от ресурсов;
- средний выигрыш в игре;
- частоты исходов `CC`, `CD`, `DC`, `DD`;
- показатель пространственной кластеризации одинаковых генотипов.

## Визуализация и отчётность

Для каждой серии строятся:

- временные ряды доли сотрудничества;
- временные ряды частот ведущих стратегий;
- графики выживаемости и средней энергии;
- сравнение итоговых значений между сценариями с доверительными интервалами;
- снимки карты мира для отдельных поколений, если визуализация не искажает количественный анализ.

## Критерий готовности базового исследования

Базовая часть считается завершённой, когда для серий 1–5 получены воспроизводимые результаты, проведено не менее 30 повторов на сценарий, а в пояснительной записке разделены наблюдения, статистические результаты и интерпретации.
