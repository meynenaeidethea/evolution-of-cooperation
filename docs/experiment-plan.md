# План вычислительных экспериментов

## Цель

Проверить, как повторяемость и локальность взаимодействий, параметры генетического алгоритма и ресурсная среда влияют на сотрудничество, состав стратегий и выживаемость популяции.

## Общие правила воспроизводимости

- Для каждого сценария выполняется не менее 30 независимых запусков.
- Для каждого запуска сохраняются идентификатор сценария, номер повтора, версия модели, полный набор параметров, начальное значение `seed`, алгоритм генератора псевдослучайных чисел, версия Java, число фактически завершённых поколений, итоговый статус и результаты по поколениям.
- Для каждого сценария фиксируются значение `G` и правило назначения `seed` для повторов. Для базовой серии и её сравнений выполняются 30 повторов с номерами `r` от `1` до `30`; для повтора используется `seed = r`. Один и тот же набор из 30 seed применяется во всех сравниваемых сценариях. Повтор с тем же набором сохранённых данных должен воспроизводить те же результаты по поколениям.
- Один запуск не используется как доказательство гипотезы; выводы делаются по распределению результатов повторов.
- При сравнении сценариев изменяется один фактор, если цель эксперимента не требует исследовать их взаимодействие.

## Базовый сценарий

Базовым считается режим из [спецификации модели](model-specification.md): локальные взаимодействия, `K = 5`, случайное движение, предлагаемые стартовые параметры среды и генетического алгоритма.

Этот сценарий нужен как точка отсчёта для всех сравнений, а не как заранее ожидаемый «правильный» результат.

Перед запуском базовой серии отдельно фиксируется значение `G`; оно не меняется между повторами и сравниваемыми сценариями, если целью эксперимента не является именно длительность запуска.

## Серии экспериментов

### 1. Повторяемость игры

Сравнить `K = 1`, `K = 3`, `K = 5` и `K = 10` при неизменных остальных параметрах.

Проверяемое утверждение: повторяющиеся встречи чаще поддерживают условное сотрудничество, чем однократная игра.

### 2. Вес игры в энергетическом балансе

Сравнить `α = 0`, `0,1`, `0,2`, `0,35` и `0,5`.

Проверяемое утверждение: игра влияет на генетический состав только тогда, когда её вклад в энергию заметен; устойчивость сотрудничества может меняться нелинейно.

### 3. Локальность взаимодействий

Сравнить базовый локальный режим с контрольным режимом, в котором партнёр для игры выбирается случайно из всей живой популяции.

Проверяемое утверждение: локальность увеличивает пространственную кластеризацию и может изменять устойчивость условного сотрудничества.

### 4. Мутация

Сравнить `pm = 0`, `0,005`, `0,01`, `0,02` и `0,05`.

Проверяемое утверждение: высокая мутация поддерживает разнообразие, но способна препятствовать закреплению успешной стратегии.

### 5. Ресурсная среда

Изменять вероятность восстановления `q` и энергию ресурса `R` в пределах, заданных спецификацией.

Проверяемое утверждение: ресурсный режим влияет на выживаемость и на относительную роль выигрышей игры в приспособленности.

## Метрики

Все показатели поколения измеряются после последнего фактически выполненного такта и до создания потомков.

Для каждого поколения и запуска сохраняются:

- число живых агентов и доля выживших: число агентов, живых в конце поколения, делённое на исходную численность `N`;
- средняя и максимальная конечная энергия среди выживших агентов; при отсутствии выживших значение равно `null`;
- частоты всех 32 генотипов среди выживших агентов; при отсутствии выживших сохраняются нулевые численности и значения частот `null`;
- число действий `C` и доля действий `C` в первых раундах встреч; знаменатель — число фактически сыгранных первых раундов;
- число действий `C` и доля действий `C` во всех раундах; знаменатель — число фактически сыгранных действий;
- количества и доли исходов `CC`, `CD`, `DC`, `DD` среди всех сыгранных раундов. Первым игроком считается агент с меньшим `agentId`; при отсутствии сыгранных раундов доли равны `null`;
- суммарная энергия, полученная от ресурсов, `ΣR_i`, и средняя энергия от ресурсов на одного агента исходной популяции `N`;
- суммарный игровой выигрыш `ΣΠ_i`, средний игровой выигрыш на одного агента исходной популяции `N` и соответствующий энергетический вклад `α × ΣΠ_i`;
- показатель пространственной кластеризации одинаковых генотипов: доля неупорядоченных пар занятых соседних клеток с одинаковым генотипом среди всех неупорядоченных пар занятых соседних клеток в окрестности Мура. Каждая пара учитывается один раз; для этого используются направления вправо, вниз, вниз-вправо и вниз-влево с тороидальным переходом. При отсутствии пар значение равно `null`;
- факт вымирания и, при вымирании, номер поколения, в котором оно произошло.

## Формат результатов

Результаты сохраняются в CSV-файлах с фиксированными заголовками столбцов и кодировкой UTF-8.

- `runs.csv` содержит одну строку на запуск: идентификаторы сценария и повтора, все параметры, `seed`, генератор, версию Java, версию модели, число завершённых поколений и итоговый статус.
- `generations.csv` содержит одну строку на поколение и запуск: все агрегированные показатели поколения.
- `genotype-frequencies.csv` содержит одну строку на сочетание «запуск — поколение — генотип» и хранит численность и частоту каждого из 32 генотипов.

Значение, математически не определённое из-за пустой выборки, записывается как пустое поле CSV, а не как `0`.

## Визуализация и отчётность

Для каждой серии строятся:

- временные ряды доли сотрудничества;
- временные ряды частот ведущих стратегий;
- графики выживаемости и средней энергии;
- сравнение итоговых значений между сценариями с доверительными интервалами;
- снимки карты мира для отдельных поколений, если визуализация не искажает количественный анализ.

## Критерий готовности базового исследования

Базовая часть считается завершённой, когда для серий 1–5 получены воспроизводимые результаты, проведено не менее 30 повторов на сценарий, а в пояснительной записке разделены наблюдения, статистические результаты и интерпретации.
