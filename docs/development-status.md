# Доработка проекта, 2 ноября 2026

Исходное локальное состояние сохранено отдельными коммитами. Перед исправлениями создан
archives/pre-hardening-20261102.tar.gz: проверены внешняя SHA256 и все 3208 файлов комплекта.
История Git дополнительно сохранена в archives/pre-hardening-20261102.bundle.

## Исправления

- JavaFX хранит полный путь выбранного профиля. Произвольный файл, в том числе названный
  user.properties в другом каталоге, сохраняется после смены seed и нового запуска.
  Добавлена кнопка открытия профиля; ошибочный файл не заменяет действующий выбор.
- Выбор профиля вынесен из основного класса окна. Панель настроек переносится по строкам
  и сохраняет читаемые кнопки при длинных путях.
- Подсчет использования условных генов выполняется в той же игре, что и подсчет выплат:
  дублирующий проход по ходам удален.
- Определения сценариев отделены от runner. Контроли мутации/ресурсов сохраняют K и вес
  выплаты из переданного профиля; изменение одного фактора не сбрасывает другие.
- Новые серии поддерживают --resume. Сохраняются точный план, исходники и идентичность
  каждого запуска; checkpoints публикуются целиком после записи и проверки SHA256.
  Измененные параметры, seed, Java или исходники блокируют продолжение. Число потоков
  менять можно. Завершенные запуски не пересчитываются; неполный запуск начинается заново.
  Параллельная запись одной серии блокируется. Частично записанные агрегаты восстанавливаются
  из checkpoints в стабильном порядке.
- Переносимый HTML больше не получает заранее записанные числа и выводы исходной серии.
  Все численные формулировки, seed, n и границы риска берутся из переданных таблиц.
  Manifest и список запусков копируются внутрь отчета; карты включаются по наличию.
- Для дополнительных серий явно указана описательная интерпретация, размер семейства
  сравнений соответствует отчету. Метаданные анализа включают SHA256 самого анализатора.
- Добавлены проверка внешней и внутренних контрольных сумм архива без распаковки,
  восстановление дополнительного конвейера и сводный отчет шести профилей.
- CI выполняет сборку, короткую и полностью вымирающую серии, отчеты, Python-тесты
  и реальную сцену JavaFX под Xvfb. Ручной full_study=true включает исходные 480 запусков,
  Java/Python-анализ, карты и архив (после слияния workflow в main).

## Дополнительное исследование

[Отдельный протокол](robustness-protocol.md): 1400 новых запусков по шести профилям,
новые seed, размеры мира 10/20/30, плотности .2/.4/.6, горизонты 60/120.
Все 1400 запусков завершены: 96000 поколений и 3072000 строк генотипов.
Проверены 7799 SHA256 файлов дополнительных серий; хеш протокола совпал с копией,
сохраненной перед расчетом в каждой серии. Повторный --resume проверил готовые серии
и отчеты без повторного запуска симуляций.

Во всех пяти измененных профилях оценки normalized-1 ниже baseline, normalized-10 выше;
описательные 95% CI парных разностей не пересекают ноль. Для global-matched все шесть
интервалов включают ноль. Ресурсные различия новой группы n=80 также неточны.
Новая группа baseline имеет C=.295 против .487 в исходной выборке; результаты
не объединяются, вариативность между seed явно показана.
Исходная основная серия не объединяется с новой выборкой.

Сводка, график, CSV и проверка SHA256: [research/robustness-20261102/](../research/robustness-20261102/).
Полный конвейер: tools/run_robustness.py и tools/summarize_robustness.py.
