## Данные, графики и демонстрация

Полный отчёт, исходные CSV, все сравнения, графики и снимки мира создаются workflow **Full experiment suite** и сохраняются как artifact **full-study**. После скачивания и распаковки откройте demo.html. [Запуск полного расчёта и его artifacts](https://github.com/meynenaeidethea/evolution-of-cooperation/actions/runs/39396024698). Архив full-study доступен внизу страницы после успешного завершения и хранится 90 дней. Для долгосрочного сохранения скачайте ZIP; скрипт package_results.py позволяет включить результаты в репозиторий.

Эта таблица сохранена из выполненной локальной серии. Первичная загрузка её 14-МБ архива прервалась при сбросе рабочей среды; полный архив восстанавливается независимым повтором в GitHub Actions. Версия Java повторного расчёта будет указана в его runs.csv.

## Интерпретация

Высокая доля C не доказывает распространение условных стратегий. При изменении K меняется также энергетический вклад игры. Глобальное спаривание может менять число встреч. Случайная рассадка потомков разрушает пространственную наследственность кластеров. Одинаковые seed обеспечивают повторяемость, но не тождественную среду после расхождения траекторий.

Наблюдение более высокой средней доли C при K = 10 не равно статистически подтверждённому преимуществу после выбранной поправки. Результаты относятся к данной модели и параметрам.
