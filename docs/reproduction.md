# Воспроизведение и данные

Модель 1.0.0 использует JDK 25 и L64X128MixRandom. Для побайтового сравнения нужны одинаковые версия Java, параметры, seed, версия модели и порядок сценариев. Число потоков влияет только на порядок сообщений консоли.

## Полное исследование

```bash
./gradlew test installDist
python3 -m pip install -r scripts/requirements.txt
python3 -m unittest discover -s scripts -p 'test_*.py'
simulation/build/install/simulation/bin/simulation --scenario all --threads 4 --snapshots --output results/full
python3 scripts/analyze.py results/full
```

Workflow **Full experiment suite** сохраняет результаты в artifact **full-study** на 90 дней. После скачивания распакуйте ZIP и откройте demo.html; повторить анализ можно командой `python3 scripts/analyze.py ПАПКА`. Workflow запускается вручную после попадания в основную ветку. Для первоначальной проверки ветки предусмотрен запуск при изменении docs/results/run-request.txt.

## Формат

UTF-8, запятая, десятичная точка, LF. Ключ запуска — (scenario, repetition), seed сохранён отдельно. Пустое поле означает неопределённую величину; нулевые численности сохраняются.

| Файл | Содержание |
|---|---|
| runs.csv | Все параметры, сценарий, повтор, seed, PRNG, Java, версия модели, статус и поколение вымирания |
| generations.csv | Выживание, средняя и максимальная энергия, ресурсный и игровой вклады, встречи, раунды, действия C, CC/CD/DC/DD и кластеризация |
| genotype-frequencies.csv | Все 32 генотипа каждого поколения, численность и частота среди выживших |
| summary.csv | Средние конечных метрик, эффективное n и 95% t-интервалы |
| comparisons.csv | Попарные разности с baseline по seed, интервалы, p и поправка Holm |

Суффикс hundredths означает сотые единицы энергии. game_payoff — сумма выигрышей без энергетического множителя. Средние вклады ресурсов/игры делятся на исходную численность N, средняя энергия — на число выживших.

Число действий равно 2 × rounds, число C равно 2 × cc + cd + dc. Первый игрок имеет меньший agentId. Кластеризация измеряется после последнего такта по неупорядоченным соседним занятым клеткам с учётом тороидальных границ.

## Анализ

Единица наблюдения — независимый запуск. Сценарии используют одни и те же seed 1–30. Конечная точка — поколение G. После вымирания выживание равно нулю, а поведение и энергия не определены. Средние и 95% интервалы рассчитаны по t-распределению; сравнения попарные по seed. Общая поправка Holm применяется ко всем конечным сравнениям четырёх метрик с baseline. Интервалы разностей не скорректированы, временные интервалы поточечные.

## Демонстрация

--snapshots сохраняет конец 1-го, каждого 25-го поколения и поколения вымирания для seed 1. Цвет агента соответствует генотипу, жёлтый квадрат — ресурсу; подсказка показывает генотип и энергию. Наблюдение не использует генератор случайных чисел.

Для сохранения результатов в репозитории выполните `python3 scripts/package_results.py results/full docs/results`. Скрипт создаёт сжатые CSV, графики, отчёт и manifest.json с SHA-256 и версиями Python-библиотек.
