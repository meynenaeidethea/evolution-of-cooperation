# Анализ сохранённых результатов

Анализатор читает три общих CSV завершённой серии: `runs.csv`, `generations.csv`, `genotype-frequencies.csv`. Он не запускает модель заново, не меняет `SimulationConfig` и не перезаписывает исходные данные. Перед расчётом проверяет связи запусков, поколений и генотипов, статусы, конфигурации и уникальность seed.

```sh
./gradlew :simulation:analyzeExperiments --args='--input results/experiments/<каталог-серии>'
```

Для IntelliJ: класс `evolution.analysis.AnalysisMain`, аргументы `--input results/experiments/<каталог-серии>`. Окно JavaFX не требуется. Для задания каталога добавьте `--output results/analysis/<новый-каталог>`. Существующий каталог отклоняется. По умолчанию создаётся новый каталог с временной меткой.

## Содержимое отчёта

- `report.html`: самостоятельная страница с встроенными изображениями, итогами, парными эффектами, динамикой по семействам сценариев и частотами всех 32 генотипов. Открывается локально в браузере без сервера и интернета.
- `*.png`: графики для вставки в пояснительную записку. Точки итоговых значений сопровождаются точными, в том числе асимметричными, доверительными интервалами.
- `summary.csv`: средние конечные значения, число наблюдений и границы интервалов.
- `paired-effects.csv`: разности относительно `baseline` на совпадающих seed.
- `trajectories.csv`: средние, интервалы и число наблюдений по каждому поколению.
- `source.sha256`: контрольные суммы исходных CSV; параметры и среда также показаны в HTML.

В статистических CSV доли хранятся в диапазоне 0…1; на графиках и в HTML — проценты. Разности долей в HTML — процентные пункты. Энергия переведена из сотых в обычные единицы.

## Как читать результаты

Единица наблюдения — независимый запуск с seed. Для средних используется percentile bootstrap по seed: 20 000 выборок с возвращением, фиксированный seed 20261013, 95% интервал. Для доли завершённых запусков используется интервал Уилсона. Повторный анализ тех же CSV воспроизводит статистику.

После вымирания выживаемость до общего горизонта равна нулю. Кооперация при отсутствии игр, энергия при отсутствии живых агентов и частоты генотипов при вымирании остаются неопределёнными. Они **не** заменяются нулём. При каждом условном среднем показывается фактическое `n`; при `n=0` — прочерк. Средняя частота генотипа сначала рассчитывается внутри каждого завершённого запуска, затем усредняется по seed: большой оставшийся размер популяции не увеличивает вес запуска.

Парные эффекты используют одинаковые **значения seed**, а не номера строк или повторов. Для конечной кооперации учитываются только пары с определёнными значениями в обоих сценариях. Разница среди выживших не доказывает преимущества стратегии для всей исходной популяции.

Это разведочные интервалы без поправки на множественные сравнения, не автоматические проверки гипотез. Малые `n`, короткий горизонт и редкие игровые встречи ограничивают интерпретацию. Увеличение `K` одновременно меняет число раундов и суммарный игровой выигрыш, поэтому само по себе не изолирует эффект памяти.

Графики строятся через [XChart](https://github.com/knowm/XChart) в PNG без запуска Swing/JavaFX. Python и внешняя обработка CSV не нужны.
