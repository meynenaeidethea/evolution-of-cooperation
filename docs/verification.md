# Проверки и воспроизводимость, 20–21 октября 2026

## Фактически выполнено

- `./gradlew :simulation:build`: успешно; **112 Java-тестов, 0 ошибок и 0 падений**. Исходно было 99; добавлены проверки генетики, matched-контроля, нормировки, наблюдения, истории, кадров, энергетических границ и сохранности CSV. Существующие тестовые фикстуры, ранее перезаписывавшие свои CSV, изменены на явное восстановление собственных испорченных данных: продуктовый запрет перезаписи не ослаблен.
- Независимый эталон игры: 32×32 пары × K∈{1,2,5,10}; перспективы обоих игроков и выплаты совпадают. Это множество проверенных случаев внутри одного JUnit-теста, не тысячи независимых научных повторов.
- `python3 -m unittest discover -s tools -p 'test_*.py'`: **6 тестов**, все пройдены с реальными smoke/extinction fixtures. Проверены bootstrap, NaN, Wilson при нулевых событиях, стандартная TFT-встреча, классификация и две намеренные порчи CSV, а также полностью вымершая серия.
- Пилот: 9 запусков, seed 900001–900003, 540 поколений, 5.920 с внутри runner.
- Основная серия: **480 запусков, 28800 поколений, 921600 строк генотипов**, все 40 seed в каждом из 12 сценариев завершены; время runner **258.264 с**, два потока. Основные параметры совпадают с заранее зафиксированным протоколом.
- Две короткие серии по 6 запусков (seed 800001–800002, три сценария), одна с двумя потоками, другая с одним: `runs.csv`, `generations.csv`, `genotype-frequencies.csv` **побайтно совпадают**.
- Финальный код повторно выполнил первые два основных seed baseline (10001,10002): все строки трёх научных CSV совпали с соответствующими строками исходной основной серии. Изменения UI, проверки недопустимой энергии и защиты записи не меняют эти траектории.
- Два технических запуска (seed 700001–700002) полностью вымерли на первом такте. Расширенный отчёт успешно построен: survival=0, C/energy пусты, n=0, обращения к условным генам=0. Это проверка обработки данных, не дополнительная научная выборка.
- В основной серии проверены ключи/связи таблиц, постоянство параметров и окружения, 32 частоты и их суммы, раунды/действия/исходы/выплаты/энергия, agent-ticks/охват, статусы/горизонт/вымирание и соответствие протоколу. Проверено **2019 SHA256** основной серии и **133 SHA256** пилота.
- Java bootstrap-анализатор и независимый Python-анализатор совпали по средним, парным эффектам и n до 10⁻¹². Наибольшее расхождение границ описательных 95% CI: C — .002829 доли; выживаемость — .0001563; энергия — .281117 обычных единиц. Разные генераторы ресэмплинга объясняют Monte Carlo расхождение границ; смешения первичных данных нет.
- SHA256 исходного протокола совпадает; он не переписывался после старта серии. Разведочная проверка потери аллеля описана отдельно в [дополнении](protocol-addendum.md).

Финальная проверка завершилась успешно; [world-ui.png](https://github.com/meynenaeidethea/evolution-of-cooperation/releases/download/research-data-20261102/cooperation-study-20261020.tar.gz), [charts-ui.png](https://github.com/meynenaeidethea/evolution-of-cooperation/releases/download/research-data-20261102/cooperation-study-20261020.tar.gz), [журнал](https://github.com/meynenaeidethea/evolution-of-cooperation/releases/download/research-data-20261102/cooperation-study-20261020.tar.gz).

[CI workflow](../.github/workflows/research.yml) настроен на сборку, короткую и полностью вымирающую технические серии, статистические тесты/CSV, отчёт и UI под Xvfb.
